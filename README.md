# IT Support & Infrastructure Labs

Hands-on troubleshooting and infrastructure labs, built and documented to develop practical skills for IT technician, IT support and junior infrastructure roles.

**15 labs** across desktop support, Windows Server and Active Directory, and cloud identity. Every lab follows the same structure: **issue → troubleshooting steps → fix → confirmed result**.

Built with Windows 10/11, Windows Server 2019/2022, Active Directory, Microsoft Entra ID and VirtualBox.
